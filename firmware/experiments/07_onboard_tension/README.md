# 07_onboard_tension

MVP step 1: compute forearm EMG tension on the ESP32-S3. No Wi-Fi.

Sampling as in `06_raw_emg_stream`: 1 kHz continuous ADC (DMA) on GPIO4 (AD8232 OUTPUT), sampler task on core 1, time from the sample index. Each sample goes through `components/emg_dsp` (plain C99, no ESP-IDF API, single-precision float):

| Stage | Setting |
|---|---|
| Mains notches | 60, 120, 180 Hz biquads, -3 dB bandwidth 4 Hz each (Q = 15, 30, 45) |
| Band-pass | 45-200 Hz Butterworth, 4th-order prototype (4 biquads) |
| RMS | 200 ms window, one output every 50 ms (20 Hz) |
| Calibration | Relax baseline = RMS over 5 s: 0.5-5.5 s after boot (0.5 s for the filters to settle), or the 5 s after the button on GPIO6 (to GND) is pressed. Rejected if under 90 % of its samples are unsaturated; the previous baseline is then kept |
| Output | `normalized = RMS / baseline`; level 0 relax, 1 medium (>= 1.49x), 2 hard (>= 2.72x); -1 while calibrating or without a baseline. The ratios are **provisional** (in-sample from experiment 06) |
| Saturation | A window containing any raw sample <= 5 mV or >= 3100 mV is flagged; the last valid RMS, normalized value and level are held |

Filter coefficients: `components/emg_dsp/include/emg_coeffs.h`, generated by `analysis/design_emg_filters.py`.

Serial output (USB-Serial-JTAG), every 50 ms:

```
<sample index>,<rms mV>,<normalized>,<level>,<saturated>
```

and once per second a `# samples= ovf= dropped= bad= dsp_us_frame_avg= dsp_us_frame_max=` line; calibration results are reported as `# calibration accepted/rejected ...`.

## Host test and validation

The host test builds the same `emg_dsp.c` with the Mac compiler and feeds an experiment 06 capture through it:

```sh
make -C firmware/experiments/07_onboard_tension/host_test
firmware/experiments/07_onboard_tension/host_test/emg_host docs/data/06_forearm_emg/03_A_light_hard.log
.venv/bin/python analysis/validate_07_tension.py      # C vs float64 reference, levels, delay -> /tmp/tension07
```
